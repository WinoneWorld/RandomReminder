# 间歇 · 专注节奏

一个轻量、响应式的随机提示音专注工具。无需安装依赖，直接在浏览器中打开 `[index.html](https://winoneworld.github.io/RandomReminder/)` 即可使用。

## 功能

- 在自定义的随机间隔内播放柔和提示音，默认每 3–5 分钟
- 可开启阶段自适应随机算法：专注前段和收尾阶段偏向较短间隔，中段偏向较长间隔
- 可调整每轮专注时长、微休息秒数、长休息时长和循环次数
- 可分别开启或关闭微休息和长休息循环
- 四个阶段可独立选择提示音，并可试听：专注开始、随机提示、微休息结束、长休息切换；提供清柔长音、空灵铃、清脆双音、浑厚低音、木鱼、木琴、水滴、电子节拍和静音
- 支持暂停、继续、结束本轮和提示音开关
- 自动保存计时、提示音与间隔设置，并适配桌面和移动设备

专注流程默认四轮，轮数可调整，完成后结束本次练习。音频由浏览器 Web Audio API 即时生成，不需要额外音频文件。

自适应算法依据文章描述实现为近似版本：保留用户设定的间隔上下限，在前段和最后阶段将随机分布偏向短间隔，在中段偏向长间隔。原文没有公开精确公式。

## 本地使用

直接打开 `index.html`。浏览器通常会在用户点击“开始专注”后允许播放提示音。
